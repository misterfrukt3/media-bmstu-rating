# Рейтинг Media BMSTU — локальный экран

Красивое сайт-табло с рейтингом семестра в стилистике [mediabmstu.ru](https://mediabmstu.ru/).
Данные берутся **напрямую из Google Таблицы** и **обновляются раз в сутки сами**, без перезагрузки страницы.
Все отделы показаны **в одну строчку** (колонками).

## Как запустить

1. Дважды кликните по файлу **`Запустить рейтинг.bat`**.
2. Откроется чёрное окно сервера и автоматически — браузер с табло
   (адрес вида `http://localhost:8181` — порт сервер подбирает сам, точный адрес виден в чёрном окне).
3. Чтобы выключить — просто закройте чёрное окно.

> Никаких установок (Python/Node) не нужно — сервер работает на встроенном в Windows PowerShell.

## Логотип

Чтобы вместо зелёного значка «M» был ваш логотип:

1. Сохраните картинку логотипа в эту же папку под именем **`logo.png`**
   (лучше PNG с прозрачным фоном — фон у табло тёмный, белый логотип смотрится отлично).
2. Обновите страницу (F5). Логотип подхватится автоматически.

Если файла `logo.png` нет — показывается запасной зелёный значок «M».

## 📱 Открыть на Android (без сервера)

Табло грузит таблицу через JSONP (`<script>`), а не `fetch()` — это работает
даже при открытии файла напрямую, без `server.ps1` и без PowerShell.

1. Скопируйте на телефон папку целиком: `index.html`, `style.css`, `app.js`,
   `logo.png` (Bluetooth, кабель, облако — как угодно).
2. В файловом менеджере откройте `index.html` → выбрать браузер (Chrome).
3. Если браузер предложит скачать вместо открытия — откройте вручную через
   Chrome: адресная строка → `file:///storage/emulated/0/…/index.html`.
4. Для полноэкранного режима на киоске/телевизоре — Chrome → меню → «На
   весь экран», либо приложение вроде Fully Kiosk Browser с автозапуском.

## Что умеет

- 🏆 7 отделов колонками в одну строчку: **Видео, Продюсирование, Визуальные эффекты, SMM, Дизайн, Фото, Проекты**
- 🥇 Подсветка топ-3 (золото/серебро/бронза), полоски прогресса, плавный «отсчёт» баллов
- 🔄 **Автообновление раз в сутки** прямо из таблицы — без перезагрузки
- 🎬 **Кино-режим (сам, без кликов).** По умолчанию видны все отделы. Раз в 30 минут табло
  плавно прогоняет отделы по очереди — крупный экран каждого на 30 секунд — и возвращается
  к общему виду. Ничего нажимать не нужно
- 📈 **Движение за неделю** — у имён значки ▲/▼ с числом позиций, на сколько человек поднялся
  или опустился по сравнению с прошлой неделей (снимок сохраняется раз в сутки)
- 👑 **Смена лидера** — когда кто-то выходит на 1-е место в отделе, короткое конфетти + подпись
- 📱 **QR-код в углу** — навёл камеру телефона и открыл полную Google-таблицу
- ✨ Мягкие ambient-переливы фона, аккуратные анимации (без нагрузки)
- ⏱️ В шапке — время последнего обновления и обратный отсчёт до следующего
- 🔎 Фильтр по отделам и поиск по фамилии (для настройки на самом ноутбуке)

### Настройки кино-режима

В `app.js`, блок `CONFIG`:

| Параметр | Значение по умолчанию | Что делает |
|---|---|---|
| `CINEMA_ENABLED` | `true` | включить/выключить авто-показ отделов |
| `CINEMA_INTERVAL_MS` | 30 мин | как часто запускать прогон по отделам |
| `SPOTLIGHT_MS` | 30 сек | сколько показывать каждый отдел |
| `FADE_MS` | 500 мс | плавность перехода между видами |

## ▶️ Как запустить на ДРУГОМ компьютере

Всё работает «из коробки», ставить ничего не надо. Нужно только:

- **Windows** (PowerShell есть в любой Windows по умолчанию);
- **интернет** (чтобы тянуть данные из Google Таблицы);
- любой современный **браузер** (Chrome / Edge / Firefox).

Порядок действий:

1. **Скопируйте всю папку** `рейтинг` целиком на другой компьютер — через флешку, облако или сеть.
   Важно перенести **все файлы вместе**:
   `index.html`, `style.css`, `app.js`, `server.ps1`, `Запустить рейтинг.bat`, и `logo.png` (если добавляли).
2. На новом компьютере откройте папку и дважды кликните **`Запустить рейтинг.bat`**.
3. Откроется браузер с табло. Готово.

Возможные мелочи на новом ПК:

- **«Windows защитила ваш компьютер» (SmartScreen)** при первом запуске `.bat` — нажмите
  «Подробнее» → «Выполнить в любом случае». Это обычное предупреждение для скачанных файлов.
- **Порт занят / зарезервирован Windows.** Сервер сам перебирает список портов
  (`8181, 8123, 7777, …`) и берёт первый свободный — обычно ничего делать не нужно.
  Если вдруг все заняты, откройте `server.ps1` и добавьте свой порт в список `$ports`.
- Если хотите запускать на телевизоре/большом экране — после открытия браузера нажмите `F11`
  (полный экран) и кнопку **«авто-экран»** на табло.

> Можно положить ярлык на `Запустить рейтинг.bat` на рабочий стол, чтобы запускать в один клик.

## Настройка

Откройте `app.js`, блок `CONFIG` в самом верху:

| Параметр | Что значит |
|---|---|
| `SHEET_ID` | ID Google Таблицы |
| `GID` | ID листа «Тир листы» |
| `REFRESH_HOUR` | час суточного обновления (по умолчанию `4` — 04:00) |

Порт сервера подбирается автоматически из списка `$ports` в `server.ps1`.

## Как это устроено

- `index.html`, `style.css`, `app.js` — само табло (стиль: Montserrat + неоновый зелёный `#43ed4e` на тёмном фоне).
- `server.ps1` — крошечный локальный веб-сервер, для удобства на Windows (ярлык, стабильный `localhost`-адрес). Не обязателен: таблица грузится через JSONP, поэтому `index.html` открывается и напрямую как файл (в т.ч. на Android — см. раздел выше).
- Браузер раз в сутки сам запрашивает свежий JSON таблицы (`gviz`-экспорт) и перерисовывает рейтинг.
