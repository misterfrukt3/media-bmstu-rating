# Media BMSTU — рейтинг семестра

Статический сайт-табло с рейтингом участников Media BMSTU по отделам.

## Файлы сайта

- `index.html` — страница сайта;
- `style.css` — стили и адаптивная вёрстка;
- `app.js` — загрузка данных и логика рейтинга;
- `logo.png` — логотип сайта.

Сайт не требует Node.js, Python или отдельного backend-сервера. Файлы можно разместить на обычном хостинге или подключить к GitHub Pages/другому статическому хостингу.

## Данные

Рейтинг загружается из публичной Google Таблицы. Настройки находятся в начале `app.js`:

```js
SHEET_ID
GID
REFRESH_HOUR
```

Участники сортируются по баллам, места пересчитываются автоматически. Доступны фильтр по отделам, поиск, полноэкранный режим, недельная динамика и автоматическая смена экранов.

## Размещение на домене

Для публикации достаточно загрузить в корень сайта:

```text
index.html
style.css
app.js
logo.png
```

После загрузки сайт открывается через `https://ваш-домен.ru/`.

## Локальная проверка

Для локального просмотра можно использовать любой статический HTTP-сервер, например расширение Live Server в VS Code или встроенный сервер выбранного хостинга. Открывать страницу через `file://` не рекомендуется, поскольку браузер может ограничить запрос к Google Таблице.
