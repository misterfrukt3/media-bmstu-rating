# Media BMSTU — рейтинг семестра

Статический сайт-табло с рейтингом участников Media BMSTU по отделам.

## Файлы сайта

- `index.html` — страница сайта;
- `style.css` — стили и адаптивная вёрстка;
- `app.js` — загрузка данных и логика рейтинга;
- `logo.png` — логотип сайта.

Сайт не требует Node.js, Python или отдельного backend-сервера. Файлы можно разместить на обычном хостинге или подключить к GitHub Pages/другому статическому хостингу.

## Данные

Рейтинг загружается из публичной Google Таблицы. Настройки находятся в начале `app.js`:

```js
SHEET_ID
GID
REFRESH_HOUR
```

Участники сортируются по баллам, места пересчитываются автоматически. Доступны фильтр по отделам, поиск, полноэкранный режим, недельная динамика и автоматическая смена экранов.

## Функции сайта

- отображение рейтинга семи отделов в отдельных колонках;
- автоматическая сортировка участников по баллам;
- подсветка первых трёх мест;
- анимированный показ баллов и прогресс-бары;
- поиск по фамилии;
- фильтр по отделам;
- ручное обновление данных;
- отображение времени последнего и следующего обновления;
- движение участников за неделю на основе сохранённых снимков;
- уведомление и конфетти при смене лидера отдела;
- полноэкранный режим и автоматическая прокрутка для большого экрана;
- кино-режим с последовательным показом отделов;
- сохранение масштаба интерфейса в браузере.

## Настройка времени

Все основные настройки находятся в начале файла `app.js`, в объекте `CONFIG`.

```js
REFRESH_HOUR: 4,
POLL_MS: 6 * 60 * 60 * 1000,
CINEMA_INTERVAL_MS: 30 * 60 * 1000,
SPOTLIGHT_MS: 30 * 1000,
FADE_MS: 500,
```

Параметры:

| Параметр | Что делает | Пример |
|---|---|---|
| `REFRESH_HOUR` | час ежедневного обновления данных по местному времени браузера | `4` — 04:00 |
| `POLL_MS` | резервная проверка таблицы через заданный интервал | `6 * 60 * 60 * 1000` — 6 часов |
| `CINEMA_INTERVAL_MS` | как часто запускать кино-режим | `30 * 60 * 1000` — каждые 30 минут |
| `SPOTLIGHT_MS` | сколько показывать один отдел | `30 * 1000` — 30 секунд |
| `FADE_MS` | длительность плавной смены отделов | `500` — 500 миллисекунд |

Например, чтобы обновлять рейтинг ежедневно в 06:00, измените:

```js
REFRESH_HOUR: 6,
```

Время берётся с устройства, на котором открыт сайт. После изменения `app.js` файл нужно заново загрузить на хостинг.

## Размещение на домене

Для публикации достаточно загрузить в корень сайта:

```text
index.html
style.css
app.js
logo.png
```

После загрузки сайт открывается через `https://ваш-домен.ru/`.

## Локальная проверка

Для локального просмотра можно использовать любой статический HTTP-сервер, например расширение Live Server в VS Code или встроенный сервер выбранного хостинга. Открывать страницу через `file://` не рекомендуется, поскольку браузер может ограничить запрос к Google Таблице.
